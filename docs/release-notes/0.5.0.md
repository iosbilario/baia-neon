# Baía Neon v0.5.0 — Na Mão

Release estável dos controles para computador e celular, promovida do mesmo SHA aprovado na candidata.

## Para quem joga

- Câmera de PC controlada continuamente pelo mouse.
- Mira central sobre o ombro e disparo por raycast.
- Pointer lock com pausa segura ao pressionar `Esc`.
- Controles móveis completos para caminhada e direção em modo paisagem.
- HUD adaptado para telas menores e aviso de orientação em retrato.
